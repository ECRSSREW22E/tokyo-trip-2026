# Visual QA

Serve the repository over HTTP, open a target page at 375, 390, 430, 768, 1024 and 1440 px, load `collision-check.js`, then call `runTokyoVisualCollisionCheck()`.

Hard pass requires zero horizontal overflow and every overlap flag to be false. For dialogs, both the dialog and close control must remain inside the viewport. Required screenshots: Homepage, Rain Plan, Shopping, Restaurants, Checklist and Screen Pilgrimage at 375, 390, 430 and 1440 px.
